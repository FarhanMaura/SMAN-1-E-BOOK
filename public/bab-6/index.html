A. Pengenalan Basis Data

1. Data dan Informasi

Data adalah kumpulan fakta mentah yang tidak memiliki arti atau konteks. Sedangkan Informasi adalah data yang telah diolah atau diproses sehingga memiliki arti dan bermanfaat.

Ibaratnya, data adalah bahan mentah (wortel, kentang). Jika diolah, ia akan menjadi sayur sop yang matang (informasi).

Klasifikasi Data

  • Berdasarkan Bentuknya Bisa numerik (angka), tekstual (kata), visual (gambar), atau audio (suara).
  • Berdasarkan Sifatnya Data kualitatif (kategori/deskriptif) dan data kuantitatif (numerik hasil ukur).

3. Basis Data

Basis data (database) adalah kumpulan data yang disimpan secara sistematis di dalam komputer yang dapat diolah atau dimanipulasi menggunakan perangkat lunak (DBMS) untuk menghasilkan informasi.

Manfaat basis data: menghemat waktu dan biaya, konsistensi data, menghindari duplikasi, memudahkan akses, menjaga keamanan, dan mendukung integrasi sistem.

Bab 6 Pengelolaan Informasi3

4. Peran dalam Lingkungan Basis Data

a. Administrator Basis Data (DBA)

Menjaga dan mengelola semua data, memastikan aman, mengatur hak akses, memperbaiki masalah sistem.

b. Desainer Basis Data

Merancang cara penyimpanan dan pengorganisasian data, seperti membuat struktur tabel-tabel.

c. Pengembang Aplikasi

Membuat aplikasi komputer yang berinteraksi dengan basis data (menulis kode program dan antarmuka).

d. Pengguna Akhir (End-Users)

Orang yang menggunakan aplikasi untuk mencari atau memasukkan informasi (misal: memesan makanan).

B. Jenis-Jenis Basis Data

1. Basis Data Relasi Data disimpan dalam bentuk tabel (baris dan kolom). Paling umum digunakan untuk sistem dengan struktur data kaku.
2. Basis Data NoSQL Lebih fleksibel, tanpa struktur tabel kaku. Cocok untuk data format dokumen/objek (seperti aplikasi media sosial besar).
3. Basis Data Berbasis Cloud Disimpan di internet, dapat diakses dari mana saja.
4. Basis Data Terdistribusi Tersebar di beberapa lokasi fisik tetapi bekerja sebagai satu kesatuan, menggunakan teknologi replikasi dan big data.
Bab 6 Pengelolaan Informasi5

C. Basis Data Relasi

Entitas dan Atribut

Entitas: Sesuatu yang memiliki keberadaan unik (Peserta didik, Guru, Buku).

Atribut: Sifat/detail yang menjelaskan entitas, menjadi kolom tabel (Nama, NIS, Alamat).

Jenis-Jenis Atribut:

  • Atribut Sederhana: Tidak bisa dipecah lagi (Nama, Jenis Kelamin).
  • Atribut Komposit: Bisa dipecah (Alamat -> Jalan, RT, Kota).
  • Atribut Kunci: Unik untuk membedakan record.

Kardinalitas (Hubungan Antar Entitas)

  • One to One: 1 peserta didik dengan 1 NIS.
  • One to Many: 1 pembeli meminjam banyak buku.
  • Many to Many: Banyak siswa mengikuti banyak ekstrakurikuler.

Foreign Key (FK) Kunci Tamu. Kolom yang merujuk ke Primary Key di tabel lain. Berfungsi sebagai jembatan yang merelasikan dua tabel.

D. Sekilas SQL

Structured Query Language (SQL) digunakan untuk berinteraksi dengan basis data.

1. CREATE TABLE

CREATE TABLE buku ( id_buku INT PRIMARY KEY, judul VARCHAR(100) );

2. INSERT (Menambah Data)

INSERT INTO buku (judul) VALUES ('Laskar Pelangi');

3. SELECT (Menampilkan Data)

SELECT * FROM buku; SELECT judul FROM buku WHERE id_buku = 1;

4. UPDATE (Mengubah Data)

UPDATE buku SET judul = 'Bumi' WHERE id_buku = 1;
