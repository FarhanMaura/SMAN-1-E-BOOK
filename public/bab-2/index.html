A. Algoritma Dasar

Algoritma merupakan langkah-langkah logis yang disusun secara sistematis untuk menyelesaikan masalah atau mencapai tujuan tertentu. Konsep algoritma ini telah kamu pelajari pada fase sebelumnya, seperti cara memahami dan menuliskan urutan instruksi sederhana.

Algoritma tidak terbatas pada bidang ilmu komputer saja, tetapi prinsip algoritma dapat diterapkan pada berbagai disiplin ilmu, termasuk matematika, teknik, bahkan proses pengambilan keputusan dalam kehidupan sehari-hari (seperti resep masakan).

Desain algoritma perlu disusun dengan terstruktur dan sistematis dari permasalahan yang jelas sampai dengan solusi yang tepat, sehingga algoritma mudah dipahami oleh mesin dan manusia.

Bentuk Penyajian Algoritma

Untuk memudahkan pemahaman, bentuk algoritma dapat disajikan dalam berbagai format:

  • 1. Uraian Naratif: Menjelaskan langkah dengan bahasa sehari-hari secara berurutan. Sangat mudah dipahami orang awam.
  • 2. Pseudocode: Penulisan menyerupai kode program namun tidak terikat sintaks baku. Memudahkan transisi dari bahasa manusia ke logika koding (seperti IF-THEN-ELSE).
  • 3. Flowchart: Diagram alir menggunakan simbol grafis standar untuk merepresentasikan alur logika secara visual.
Menyajikan algoritma dalam bentuk tersebut mempermudah pemahaman solusi secara logis sebelum menerapkan ke bahasa pemrograman.

B. Implementasi Logika dalam Flowchart

Logika pemrograman adalah landasan utama untuk menyelesaikan persoalan melalui kode. Pemahaman logika mempercepat penulisan program dan optimasi. Terdapat beberapa jenis logika pemrograman.

1. Logika Urutan (Sequence Logic)

Instruksi secara berurutan dari atas ke bawah. Setiap pernyataan dieksekusi satu per satu tanpa percabangan.

// Menghitung Rata-rata Input(Nilai A, Nilai B) Total = Nilai A + Nilai B Rata = Total / 2 Output(Rata)
Bab 2 Algoritma & Pemrograman8

2. Logika Seleksi / Percabangan

Logika yang digunakan untuk membuat keputusan berdasarkan kondisi (seperti IF, IF-ELSE, atau SWITCH-CASE). Operator logika aritmatika, perbandingan, dan boolean digunakan untuk mengevaluasi kondisi.

Pengondisian Bertingkat (Nested If)

Sebuah struktur pengondisian di mana satu pernyataan IF berada di dalam blok IF atau ELSE lainnya. Ini memungkinkan pengambilan keputusan yang sangat kompleks dan bertingkat.

IF (Kondisi 1) THEN IF (Kondisi 2) THEN // Jalankan A ELSE // Jalankan B ENDIF ENDIF

3. Logika Perulangan (Looping)

Logika ini digunakan untuk mengeksekusi blok kode secara berulang selama kondisi tertentu terpenuhi. Struktur perulangan sangat penting untuk efisiensi kode. Contohnya: FOR, WHILE DO, REPEAT UNTIL.

Pengulangan Bersarang (Nested Loop)

Struktur kontrol yang terdiri dari satu pengulangan (loop) di dalam pengulangan lainnya. Saat loop luar berjalan sekali, loop dalam akan berjalan sepenuhnya sebelum loop luar pindah ke iterasi berikutnya.

FOR i = 1 TO n DO FOR j = 1 TO n DO // Jalankan proses berulang ENDFOR ENDFOR

4. Algoritma Pencarian (Searching)

a. Sequential Search (Linear)

Algoritma pencarian paling sederhana. Bekerja dengan cara memeriksa elemen satu per satu, dari awal sampai akhir. Pencarian berhenti jika data ditemukan. Keuntungannya: data tidak perlu terurut. Kerugiannya: lambat untuk data besar.

// Array A = [1, 5, 10, 7, 15] Input(x) // nilai yg dicari posisi = -1 FOR i = 0 TO n - 1 DO IF A[i] == x THEN posisi = i BREAK // Keluar dari loop ENDIF ENDFOR
Contoh: Jika mencari nilai 10, program akan mengecek A[0] (salah), A[1] (salah), lalu A[2] (Benar!).
Bab 2 Algoritma & Pemrograman13

b. Binary Search

Algoritma pencarian yang efisien, TAPI syaratnya data harus sudah diurutkan. Bekerja dengan membagi array menjadi dua bagian lalu membandingkan nilai yang dicari dengan elemen tengah.

awal = 0 akhir = n - 1 posisi = -1 WHILE (awal <= akhir) DO tengah = (awal + akhir) DIV 2 IF A[tengah] == x THEN posisi = tengah BREAK ELSE IF x < A[tengah] THEN akhir = tengah - 1 ELSE awal = tengah + 1 ENDIF ENDWHILE

5. Algoritma Pengurutan (Sorting)

a. Selection Sort

Algoritma sederhana yang bekerja dengan cara mencari nilai terkecil/terbesar dari data yang belum terurut, lalu menukarnya ke posisi paling awal. Proses ini diulangi untuk sisa data.

Contoh Array: [6, 3, 8, 5, 2]

1. Cari nilai terkecil dari indeks 0 hingga akhir. Didapat 2. Tukar dengan posisi pertama.
Hasil: [2, 3, 8, 5, 6]

2. Cari nilai terkecil dari indeks 1 hingga akhir. Didapat 3. Tidak perlu ditukar.
Hasil: [2, 3, 8, 5, 6]

3. Cari nilai terkecil dari indeks 2 hingga akhir. Didapat 5. Tukar dengan indeks ke-2.
Hasil: [2, 3, 5, 8, 6]

Bab 2 Algoritma & Pemrograman16

b. Insertion Sort

Bekerja seperti seseorang menyusun kartu di tangan saat bermain remi. Setiap elemen dipilih satu per satu dan disisipkan pada posisi yang sesuai dalam bagian data yang sudah terurut di sebelah kirinya.

Contoh Array: [5, 2, 4, 6, 1]

1. Mulai elemen ke-2 (yaitu 2), bandingkan dengan 5. Karena 2 < 5, geser 5 ke kanan, sisipkan 2.
Hasil: [2, 5, 4, 6, 1]

2. Elemen ke-3 (yaitu 4), bandingkan dengan kiri (5 > 4). Geser 5 ke kanan, sisipkan 4.
Hasil: [2, 4, 5, 6, 1]

Jumlah pertukaran pada Insertion Sort lebih banyak karena sering menggeser elemen.

C. Algoritma Terstruktur

1. Array

Struktur data adalah cara mengatur dan menyimpan data secara efisien. Salah satu bentuk yang paling dasar adalah Array. Array menyimpan sekumpulan nilai dengan tipe data yang sama dalam satu variabel.

Kamus A : array of Integer // Mengisi Array A = [10, 2, 30, 4] // Akses Elemen A[0] = 10 A[3] = 4 // Operasi Matematika Jumlah = A[1] + A[3] // 2 + 4 = 6

2. Algoritma Rule Based

Algoritma berbasis aturan (Rule Based) adalah bentuk pengambilan keputusan paling dasar dalam Kecerdasan Artifisial (KA). Sistem ini bekerja murni berdasarkan aturan yang ditulis manusia (If-Then atau Nested If).

Sistem Pakar Diagnosa Kesehatan

IF suhu > 37.5 THEN IF batuk == "ya" THEN IF sakit_kepala == "ya" THEN Output("Diagnosa: Terkena Flu/Virus") ELSE Output("Diagnosa: Demam dan Batuk") ENDIF ENDIF ENDIF

Walaupun terlihat cerdas, sistem ini kaku karena hanya bisa mengambil keputusan dari aturan yang sudah didefinisikan eksplisit.

d. Naive Bayes

Metode untuk klasifikasi atau prediksi yang didasarkan pada Teorema Bayes (Probabilitas bersyarat). Ia menghitung kemungkinan suatu kejadian terjadi berdasarkan informasi lampau.

Rumus Naive Bayes

P(A|B) = P(A ∩ B) / P(B)

Menghitung probabilitas bersyarat A terhadap B.

  • Sangat cepat untuk dataset sangat besar.
  • Biasa dipakai di Filter Spam Email dan Klasifikasi Sentimen.
Bab 2 Algoritma & Pemrograman25

Contoh Naive Bayes

Menebak Buah baru (Ukuran=Kecil, Rasa=Manis) dari data tabel sejarah.

Probabilitas Apel:

P(Apel|Kecil,Manis) = P(Apel) * P(Kecil|Apel) * P(Manis|Apel)

= 0.33 * 0.33 * 0.67 = 0.072

Probabilitas Anggur:

P(Anggur|Kecil,Manis) = P(Anggur) * P(Kecil|Anggur) * P(Manis|Anggur)

= 0.33 * 0.67 * 1 = 0.22

Kesimpulan: Karena probabilitas Anggur (0.22) lebih besar dari Apel (0.072), AI memprediksi buah tersebut adalah Anggur!

E. Sintaks Dasar Pemrograman

Setiap bahasa memiliki aturan sintaks (tata bahasa) sendiri.

1. Bahasa C

  • Harus punya fungsi main()
  • Setiap baris wajib diakhiri titik koma (;)
  • Case-sensitive (huruf besar/kecil berbeda)
#include <stdio.h> // Pustaka I/O int main() { /* Menampilkan teks ke layar */ printf("Halo, dunia!\n"); return 0; }
Bab 2 Algoritma & Pemrograman30

2. Bahasa Python

Bahasa tingkat tinggi yang paling simpel & populer untuk AI.

  • Tidak wajib ada fungsi main.
  • Tidak butuh titik koma (;).
  • Menggunakan indentasi (spasi/tab) untuk blok kode.
# Komentar di Python pakai hashtag nama = input("Masukkan nama: ") print("Selamat datang", nama)
Konversi Tipe Data:
int("123") ➔ Mengubah teks jadi angka bulat.
float("1.5") ➔ Mengubah teks jadi pecahan.

3. Bahasa Java

Bahasa berbasis Class (Object Oriented) yang berjalan di berbagai platform.

  • Semua kode harus di dalam class.
  • Nama file harus sama dengan nama class (cth: Halo.java).
  • Wajib fungsi main dan titik koma (;).
public class Halo { // Titik awal eksekusi public static void main(String[] args) { System.out.println("Halo, dunia!"); } }

Di antara ketiga bahasa ini, Python sangat disarankan untuk pemula yang ingin belajar Data Science atau AI karena penulisan bahasanya mirip dengan struktur berpikir manusia.

Debugging adalah proses mencari, menemukan, dan memperbaiki bug (kesalahan) dalam program.

1. Syntax Error

Kesalahan tata bahasa kode. Compiler menolak program untuk jalan.

// Java (Kurang titik koma) System.out.println("Halo") // Python (Salah ketik perintah) pint("Halo")

Program berjalan lancar tanpa terhenti, tapi hasilnya SALAH. Sangat susah dideteksi.

// Niatnya menjumlahkan a dan b hasil = a - b; // Error Logika (operator salah)
